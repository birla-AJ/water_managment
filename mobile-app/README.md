# WaterFlow — Customer Mobile App (React Native CLI)

Customer-facing app for the WaterFlow ERP. Built with React Native CLI + TypeScript.

## Stack
- React Native CLI 0.75 + TypeScript
- Redux Toolkit + React Redux
- React Navigation (native-stack + bottom-tabs)
- Axios (with refresh-token interceptor)
- Firebase Cloud Messaging (`@react-native-firebase/*`)
- Razorpay (`react-native-razorpay`)

## Screens
Splash · OTP Login · OTP Verify · Home · My Deliveries · Order Camper · Order History · Billing · Payment History · Notifications · Profile · Support

## Setup

```bash
npm install
cd ios && pod install && cd ..   # iOS only

# Android emulator reaches host backend at http://10.0.2.2:4000
npm run android
# or
npm run ios
```

### Configuration
Edit `src/config.ts` (or wire `react-native-config`) to set:
- `apiUrl` — backend base URL
- `razorpayKeyId` — your Razorpay key id

### Firebase (push notifications)
1. Create a Firebase project.
2. Add Android app → download `google-services.json` → `android/app/`.
3. Add iOS app → download `GoogleService-Info.plist` → add to the Xcode project.
4. The app requests permission and registers the FCM token via `PATCH /auth/fcm-token` on login.

### Razorpay
Install the native module per the [react-native-razorpay docs](https://github.com/razorpay/react-native-razorpay). The checkout flow:
`POST /me/payments/razorpay-order` → open checkout → `POST /me/payments/verify`.

## Auth flow
Mobile number → OTP (dev OTP is `123456`, shown in an alert in non-prod) → JWT access + refresh tokens persisted in AsyncStorage.

> Native `android/` and `ios/` folders are generated by `npx react-native init`. Drop these JS/TS sources into a fresh RN project, or run init with the same app name `WaterFlowCustomer`.
